# Changelog

## 0.2.0

- Updated highlighting for the `cxx.embed` and `cxx.extract` markers.
- Supports the `.tag<T>('name')` form on both markers.
- Handles escaped backticks inside CSS.

## 0.1.0

- Initial release.
- Injection grammar that highlights CSS inside `cxx\`...\`` and `cxx.tag<T>('name')\`...\`` tagged template literals across TypeScript, TSX, JavaScript, JSX and the `.mts` / `.mjs` / `.cjs` variants.

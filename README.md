# cxx

Monorepo for `cxx` - build-time CSS template tag utilities for React 19 and Solid 2.

## Packages

| Package | Description |
| --- | --- |
| [`@jk2908/cxx`](./packages/cxx) | Core runtime, build-time transform (Vite, Next), and the `react` and `solid-js` `Style` entries |
| [`vscode-cxx`](./packages/vscode-cxx) | VS Code extension: syntax highlighting for `cxx` tagged templates |

See each package's README for install, usage, and configuration.
